# Somno Studio 🎧

Minimalist professional Ambient Audio Mixing Console designed to provide personalized soundscapes for deep sleep, focus, and meditation. Built with Next.js 14+ (App Router), TypeScript, Tailwind CSS, and Web Audio API.

## Features

- **11 Channel Strips**: Heavy Rain, Deep Sleep, Ocean Waves, Cabin Fire, Cosmic Drone, Forest Night, Soft Wind, Tibetan Bowl, Vinyl Crackle, River Stream, and Theta Waves.
- **Pure Web Audio DSP Synthesis**: Zero external `.mp3` files, instant playback, seamless looping without gaps, and complete offline capability.
- **Stereo Panning & VU Meters**: Real-time signal visualization and spatial sound separation.
- **Presets & Sleep Timer**: Quick blend presets and automated sleep countdown timer (15m, 30m, 45m, 60m).
- **State Persistence**: Automatic local storage of your favorite mix configurations.
- **Dark Aesthetic**: Eye-friendly dark UI (`#08090d`) optimized for single viewport (`100vh`) usage.

## Getting Started

1. Clone or extract this repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment on Vercel

Push this repository to GitHub and import it into Vercel with zero configuration needed.
